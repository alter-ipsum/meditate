
# Meditation

## Simple meditation application implemented using React. 

### Overview 

A selection of themes are available via a theme selector palette, which alters
both the sound and color used. The application is completely responsive, and
the main icon pulsates inline with a calm breathing pace while playing soothing
sound effects.

### Run

1. Install all necessary NPM modules within *package.json* by: `npm install`
2. Then, run and open the application in the default browser with: `npm start`
